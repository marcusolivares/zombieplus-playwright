# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

ZombiePlus is an automated E2E test suite for a streaming platform administration system. The application under test manages zombie-themed movies, TV shows, and user leads (waitlist) with:
- Public landing page with waitlist signup
- Admin portal for CRUD operations on movies, TV shows, and leads

**Tech Stack:** Playwright + TypeScript + PostgreSQL + Faker.js

## Commands

```bash
# Run all tests headless
npm test

# Interactive Playwright UI
npm run test:ui

# Debug mode with inspector
npm run test:debug

# View HTML test report
npm run test:report

# Run only agent-generated tests
npx playwright test --grep @agent

# Run a single test file
npx playwright test tests/e2e/movies.spec.ts

# Run tests matching a pattern
npx playwright test -g "should be able to register"
```

## Architecture

### Fixture-Based Page Objects

Tests import from `tests/support/index.ts` which extends Playwright's base test with custom fixtures:

```typescript
import { test, expect } from '../support'

// Page objects are attached to the page instance
await page.login.do(email, password, username)
await page.movies.create(movieData)
await page.popup.haveText(successMessage)
```

**Available page fixtures:** `page.login`, `page.movies`, `page.tvshows`, `page.leads`, `page.popup`

**API fixture:** `request.api` - Pre-authenticated API helper for test data setup

### Key Files

| File | Purpose |
|------|---------|
| `tests/support/index.ts` | Fixture setup, extends Playwright test |
| `tests/support/constants.ts` | Selectors, error/success messages (Portuguese) |
| `tests/support/database.ts` | `executeSQL()` for database operations |
| `tests/support/actions/*.ts` | Page Object Model classes |
| `tests/support/fixtures/*.json` | Test data for movies/tvshows |

### Test Data Management

- **Database cleanup:** Use `beforeEach(() => executeSQL('DELETE from movies'))` for isolation
- **API seeding:** Use `request.api` methods (returns 409 if already exists)
- **JSON fixtures:** Predefined test data in `tests/support/fixtures/`

### Configuration Notes

- Single worker execution (shared database state)
- Chromium only, 1920x1080 viewport
- Environment variables loaded via dotenv from `.env`
- UI messages are in Portuguese

## AI Agent Integration

Three Playwright MCP agents are configured in `.claude/agents/`:

- **playwright-generator:** Generates tests by recording browser interactions
- **playwright-healer:** Debugs and fixes failing tests
- **playwright-planner:** Creates test plans by exploring the UI

Tests generated by agents are tagged with `@agent`.
